# Visual Sound

## Abstract

[EN]
Visualizing sound, or more specifically music, can really enhance the experience. You are using an additional sense after all!

Tailored visualizations have been around for a long time and have been a staple of live concerts and other forms of live music for a long time. Computer driven visualizers have also been around a while, who can forget good old WinAmp?

But how do you extract features from sound so that you can visualize it? This short talk will take you through some of the most approachable audio features, what they represent in a piece of audio, and how we can use them in a visualizer.
